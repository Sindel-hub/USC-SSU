# Primary Officer Module Ownership

The default RBAC presets now assign a clear manager to the two sensitive officer modules.

## Election Management
**Primary manager: Vice President**

Default election permissions:
- Assigned Election Module
- Manage Election Schedule
- Manage Voter Roster
- Review Candidates
- Finalize / Publish Results

The President and other officers may still open Elections in read-only mode unless the System Administrator grants additional election permissions.

## Complaint Management
**Primary manager: President**

Default complaint permissions:
- Assigned Complaint Module
- Review Complaints
- Classify Complaints
- Provide USC Feedback
- Update Complaint Status
- Generate Complaint Reports

The Vice President and other officers may still open Complaints in read-only mode unless the System Administrator grants additional complaint permissions.

## Overrides
These are position defaults. System Administrator custom permissions still take priority.
