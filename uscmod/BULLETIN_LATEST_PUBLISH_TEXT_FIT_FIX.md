# Bulletin Latest Publish Text Fit Fix

The Latest Publish summary card no longer truncates the publish date with an ellipsis on narrow layouts.

## Changes
- Removed one-line ellipsis behavior from the latest publish date.
- Allowed the full date to wrap naturally when necessary.
- Kept the time readable below the date.
- Ensured the `Most recent live post` helper text remains fully visible.
- Tightened spacing and typography for medium-width desktop layouts.
- Bumped the Bulletin Board stylesheet cache version to `v=4`.
