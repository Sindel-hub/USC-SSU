# Officer Overview Event Liveliness Update

Updated the officer dashboard main overview to make the Events panel feel more alive and informative.

## What changed

- Polished the Events card with a stronger spotlight treatment for the next event
- Added event badges for registration state
- Added three quick insight metrics: countdown, portal registrations, and registration mode
- Added an upcoming-events queue with category and registration counts
- Enhanced the mini calendar with today/focus-day visual emphasis
- Added a cache-bust version update for overview CSS and JS
